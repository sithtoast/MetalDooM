# Reporting a MetalDooM problem

Report issues at https://github.com/sithtoast/MetalDooM/issues.

1. Choose **Diagnostics → Copy Diagnostic Report** and paste it into the issue.
   It includes the app/build, Mac/GPU, settings, campaign/map and loaded WAD hashes.
2. Explain what you did, what you expected and what happened. Include the map and
   whether the issue happens during gameplay or an automatic demo.
3. Add a screenshot or short recording when helpful. For crashes, attach the
   MetalDooM crash report from macOS Console.
4. You can also attach **Diagnostics → Export Session Log…** or a benchmark result.

Review logs and crash reports for personal information before posting.
Never attach commercial WADs, save files containing sensitive data, signing keys
or passwords. WAD filenames and hashes are enough to identify the game data.

See INSTALL.md for first-launch instructions and PLAYER_GUIDE.md for controls.
Contributor testing details: https://github.com/sithtoast/MetalDooM/blob/main/docs/TESTING.md
