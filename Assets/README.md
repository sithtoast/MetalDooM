# App icon

`AppIcon.png` is the selected standalone Apple Metal M concept in Doom gold-to-blue-steel colors. The user selected this design for the app.

The original concept was generated with the built-in image generation tool. With user approval, local image processing removed the baked-in checkerboard outside the rounded tile and feathered its boundary inward by less than one source pixel. Opaque artwork pixels are unchanged from the selected original.

The app build uses `scripts/build-icon.sh` to generate standard and Retina macOS sizes and package them as `AppIcon.icns`.

Generation prompt:

Use case: logo-brand. Create one square macOS app icon brainstorming concept, using the supplied MetalDooM icon as an edit target. Keep the recognizable heavy angular classic Doom D O O lettering and the distinctive Apple Metal zigzag M silhouette at the end when present. The Metal M has two sharp diagonal folded peaks and a descending diagonal right stroke; never substitute a normal typographic M. Dark charcoal rounded-square tile, centered composition, same industrial bronze/steel aesthetic. Reduce orange glow to restrained edge highlights. Actual transparent alpha outside the rounded tile: DO NOT draw checkerboard squares; the checkerboard in the reference is not part of the artwork. No labels, no extra text, no scenery, no watermark. Variant 3: STANDALONE APPLE METAL M IN DOOM STYLING. Remove D and both O letters completely. Use ONLY the final Apple Metal zigzag M shape from the reference, enlarged into one centered bold emblem occupying about 76 percent of tile width and height. Preserve that asymmetrical angular folded double-peak silhouette faithfully; do not use a conventional serif M. Give this single Metal M the classic Doom treatment: gold/bronze upper face grading to blue-gray steel lower face, chunky dimensional bevels, restrained battle-worn texture, subtle warm lighting. Strong small-size legibility and minimal empty space. One emblem only, no other letters.
